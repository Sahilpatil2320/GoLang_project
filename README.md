💬 GoLang Real-Time Chat Application 🚀

A real-time chat application built with Go (Golang) and
WebSockets for instant two-way communication between connected
users.

This project was created to gain practical experience with Go backend
development, WebSocket communication, client-server architecture, and
frontend-backend integration.

🔄 How the Application Works

The application uses WebSockets to maintain a continuous connection
between the browser and the Go server.

Client → WebSocket Connection → Go Server → Connected Client(s)

WebSockets allow the client and server to exchange messages continuously
over the same connection, making them suitable for real-time
applications.

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/Sahilpatil2320/GoLang_project.git

2. Navigate to the Chat Application

cd GoLang_project/chat-app

3. Download Dependencies

go mod download

4. Run the Application

go run main.go

5. Open the Application

Open the local address provided by the Go server in your browser.

Open the application in multiple browser tabs/windows to test real-time
communication.

🧪 Testing the Chat

Start the Go server.

Open the chat application in a browser.

Open another browser tab/window.

Connect both clients.

Send a message from one client.

Verify that the message is received in real time.
